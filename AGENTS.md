## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Multi-context: root `docs/adr/` for system-wide decisions, plus `pkg/<context>/CONTEXT.md` and `pkg/<context>/docs/adr/` created lazily per context. See `docs/agents/domain.md`.
